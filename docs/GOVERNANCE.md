# Governance
- Experimental research only; never a safety certification or go/no-go tool.
- Never claim a specific flight, operator, crew or airframe will crash.
- No absolute probability until calibration supports it.
- Forecasts freeze before outcomes and remain immutable.
- Evaluations are separate append-only records.
- Corrections create a new version; history is never rewritten.
- Point-in-time provenance is mandatory; future leakage is a test failure.
- Missing data reduce confidence and are never negative evidence.
- Restricted/licensed raw data and secrets are never committed.
