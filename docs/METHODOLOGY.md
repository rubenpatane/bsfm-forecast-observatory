# Methodology
BSFM v1.2 decomposes risk into exposure, technical precursors, mitigation, failure hazard, escalation, phase, geography and survival/time-to-event, with hierarchical shrinkage. MSN is a persistent airframe identity where public linkage supports it. Missing maintenance/operational data remain missing, never adverse evidence.

Walk-forward reverse backtest uses T-365/T-90/T-30/T-7 cutoffs with strict no-future-leakage. Metrics include variant/event-class/phase, temporal absolute error, hit rates ±30/14/7/3/1 days, calibration and comparison with an exposure-only null model. No-event periods are included.
