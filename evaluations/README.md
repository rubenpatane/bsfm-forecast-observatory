# Evaluations
Append-only outcome records are separate from forecasts. Each records ground-truth source, retrieval/publication dates, matching rule and model-independent score. Evaluation never mutates a frozen prediction.

`public-data-extended-training-feasibility.json` is a fail-closed exploratory
audit, not a model scorecard. It records why a seemingly positive frozen-prior
result cannot be promoted and includes an equal-total-prior sensitivity that is
negative and inconclusive.
